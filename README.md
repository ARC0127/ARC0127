## Research

**[Fisher Decorator: Refining Flow Policy via a Local Transport Map](https://arxiv.org/abs/2604.17919)**  
NeurIPS 2026 · **Co-first author**  
Xiaoyuan Cheng\*, **Haoyu Wang\***, Wenxuan Yuan, Ziyan Wang, Zonghao Chen, Li Zeng, Zhuo Sun.  
\* Equal contribution.

This work uses a Fisher-guided local transport map to refine flow policies while preserving multimodal behavior. It achieves state-of-the-art results on **OGBench and D4RL**, with simulated robot locomotion and manipulation tasks using state and visual inputs.

[Paper](https://arxiv.org/abs/2604.17919) · [Code](https://github.com/ARC0127/Fisher-Decorator) · [![GitHub stars](https://img.shields.io/github/stars/ARC0127/Fisher-Decorator?style=flat&label=Stars)](https://github.com/ARC0127/Fisher-Decorator/stargazers)

**[GEM: Guided Expectation-Maximization for Behavior-Normalized Candidate Action Selection in Offline RL](https://arxiv.org/abs/2603.23232)**  
arXiv, March 2026 · **First author**  
**Haoyu Wang**, Jingcheng Wang, Shunyu Wu, Xinwei Xiao.

This work combines Gaussian-mixture policies, value estimates, and behavior support to select actions from multimodal offline data. Evaluated on **D4RL Locomotion, AntMaze, and Maze2D**, it lets inference compute be adjusted without retraining the policy.
